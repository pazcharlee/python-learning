# Chapter 3: Functions and Modules

## Overview

Chapter 3 introduced the use of **functions and modules** in Python. The focus was on learning how to organize code into reusable pieces rather than writing an entire program as one continuous sequence of statements.

## Topics Covered

* Defining and calling functions
* Function parameters and arguments
* Return values
* Default parameter values
* Named arguments
* Local and global variables
* Using functions from other modules
* Planning programs with functions
* Hierarchy charts


## Key Takeaways

The main lesson from this chapter was that functions allow a program to be broken into smaller, reusable pieces. Instead of having all of the program's logic in one place, related tasks can be placed inside individual functions and called when needed.


## Skills Practiced

By the end of the chapter, I was able to:

* Define and call functions.
* Pass information into functions through parameters.
* Return values from functions.
* Use default and named arguments.
* Understand the difference between local and global variables.
* Break larger problems into smaller functions.
* Plan program structure before writing the code.
